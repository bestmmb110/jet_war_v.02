# راهنمای نصب کنترلر آردوینو Pro Micro برای Jet War

## ۱) سیم‌کشی (دکمه‌ها بین پین و GND، بدون مقاومت خارجی)

| پین | وظیفه | معادل کیبورد/ماوس |
|---|---|---|
| D2 | چرخش چپ | A |
| D3 | چرخش راست | D |
| D4 | شلیک | کلیک چپ / Ctrl |
| D5 | تعویض سلاح | کلیک راست / Alt |
| D6 | تعویض دوربین | C |
| D7 | شروع / بازگشت | Enter |
| D8 | خروج | Esc |
| D9 | دکمهٔ جوی‌استیک (مرکزدهی) | - |
| A0 | جوی‌استیک محور X | حرکت ماوس افقی |
| A1 | جوی‌استیک محور Y | حرکت ماوس عمودی |
| A2 | پتانسیومتر سرعت | جایگزین Space |

جوی‌استیک و پتانسیومتر: دو پایهٔ کناری به 5V و GND، پایهٔ وسط به پین آنالوگ.

## ۲) آردوینو
فایل `JetController.ino` را با برد **Arduino Leonardo / Pro Micro (5V/16MHz)** آپلود کنید.

## ۳) یونیتی
1. `ArduinoSerialBridge.cs` را در `Assets/Scripts/` بگذارید (فایل جدید؛ فایل‌های اصلی تغییر نمی‌کنند).
2. `Edit > Project Settings > Player > Other Settings > Api Compatibility Level = .NET Framework`
3. یک GameObject خالی در صحنهٔ اول (صحنهٔ نبرد زنده) بسازید و این اسکریپت را روی آن بگذارید. `portName` خالی = تشخیص خودکار، یا مثلاً `COM5`.
4. این اسکریپت کلید/ماوس واقعی ویندوز را تزریق می‌کند، پس کیبورد و ماوس همزمان کار می‌کنند و اسکریپت‌های اصلی بدون تغییر پاسخ می‌دهند.
5. اگر جهت بالا/پایین وارونه بود، `invertY` را تغییر دهید.

## ۴) پتانسیومتر به‌جای Space
مقدار `ArduinoInput.Pot01` (بین ۰ تا ۱) در دسترس است. فرمول سرعت:

    float speedKmh = Mathf.Lerp(300f, 3500f, ArduinoInput.Pot01);

در `SpaceSpeedControl.cs` (یا یک اسکریپت جدید که آن را غیرفعال می‌کند) باید این مقدار جای منطق Space بنشیند، وقتی `ArduinoInput.Connected == true`. برای نوشتن دقیق آن، محتوای فایل `SpaceSpeedControl.cs` را برایم بفرستید.
